## Задача 5
### Текст задачи
Добавление массива в массив.  
Дана сигнатура метода: public int[] add (int[] arr, int[] ins, int pos); 
Необходимо реализовать метод таким образом, чтобы он возвращал новый 
массив, который будет содержать все элементы массива arr, однако в позицию 
pos будут вставлены значения массива ins. 
 
Пример: 
arr=[1,2,3,4,5] 
ins=[7,8,9] 
pos=3 
результат: [1,2,3,7,8,9,4,5]
### Алгоритм решения
Если pos меньше 0 или pos больше или равна длине arr, выводится сообщение "Pos error" и возвращается null. Иначе создаётся новвый массив целых чисел arr2 с длинной равной длине arr и ins вместе, затем создается переменная ptr1, равная 0 и показывающая на какое место в arr2 надо записывать новый символ. Далее в итераторе i(от 0 до длины arr) идёт прохождение по массиву, и если i становится равна pos, то в итераторе j(от 0 до длины ins) на ptr1-место массива arr2 вставляется j-ый элемент массива ins и ptr1 становится на 1 больше, иначе на ptr1-место массива arr2 вставляется i-ый элемент массива arr и ptr1 становится на 1 больше. Возвращается массив arr2.

## Задача 9
### Текст задачи
Все вхождения.  
Дана сигнатура метода: public int[] findAll (int[] arr, int x); 
Необходимо реализовать метод таким образом, чтобы он возвращал новый 
массив, в котором записаны индексы всех вхождений числа x в массив arr. 
 
Пример: 
arr=[1,2,3,8,2,2,9] 
x=2 
результат: [1,4,5]  
### Алгоритм решения
Для решения данной задачи использовался динамический массив ArrayList. В начале он создаётся с именем list, далее в итераторе i(от 0 до длины arr) идёт прохождение по массиву, и если х равняется значению i-ого элемента, то в list добавляется значение i. При возврете list преобразуется в поток в котором все числа становятся типа int и преобразуются в статический массив.
